# C# Practice: ConstantVariables

This project is part of the **CSharpPractice** repository, practicing concepts from **Chapter 1: Variables**.

## Topic
**Constants**

## Exercise Requirements
Write a program (ConstantVariables) that define constants for common mathematical values such as PI (π) = 3.1415926536 and the speed of light (C) = 299 792 458 m/s.
In the program use these constants in calculations and display the results with appropriate labels.
Declare radius and distance of datatype double declared on the same line (multiple variable declaration)
Area of a Circle (Earth)  where radius (test with radius = 6 371 000 in metres) prompted from user.
How long (time = distance / speed) it will take from Earth to moon (test with distance = 384 400 000 metres) prompted from user, when travelling at the speed of light.
Boolean
